**①の Search Console 登録は、この引っ越しが終わってから行ってください**（新しいアドレスで登録するためです）。

1. **組織を作る**：https://github.com/account/organizations/new?plan=free を開く

2. **リポジトリを組織へ移す**：https://github.com/sasurainoebitiri-code/-sunrise/settings を開き、いちばん下の「Transfer」

3. **リポジトリ名を変える**：移動後のリポジトリの「Settings」→「Repository name」を `sunrise-kaitai.github.io` に変えて「Rename」
   - 続けて左メニューの「Pages」を開き、「Source」が「Deploy from a branch」、Branch が「main」「/ (root)」になっていることを確認（違っていたらそう設定して「Save」）

5. Claude に「引っ越し終わった」と送ってください。新しいアドレスで公開し直し、表示の確認まで行います。

※ 2〜5 の間は、一時的にサイトの表示が崩れることがあります。まとめて続けて行うのがおすすめです。

## ④ 独自ドメインを取る（年に数千円ほど・あとで大丈夫です）

無料の「sunrise-kaitai.github.io」でも十分に運用できますが、「.jp」などの独自ドメインにすると、さらに信頼されやすく、覚えてもらいやすくなります（余裕ができたときで大丈夫です）。

1. お名前.com・ムームードメイン・Cloudflare などでドメインを購入します。
   - 候補の例：`sunrise-kaitai.jp`、`sunrise-kaitai.com`、`sunrise-ama.jp`（空いているかどうかは購入サイトで確認してください）
   - 法人なら `co.jp` も取れます（登記の確認があるため少し時間がかかります）。
2. 購入したら、ドメイン名を Claude に教えてください。サイト内のアドレスの切り替え、canonical・サイトマップの更新は Claude が行います。
3. その後、次の2つをお願いします（画面の場所はそのときに案内します）。
   - ドメインを買った会社の管理画面で、DNS に GitHub Pages 用の設定を追加する
   - GitHub のリポジトリの「Settings → Pages → Custom domain」にドメインを入力し、「Enforce HTTPS」にチェックを入れる
   - 切り替え後は、古い github.io のアドレスから新しいドメインへ GitHub が自動で転送します。

## ⑦ 公式LINEのログイン管理を始める（2026/10/28 作成・あとは設定だけ）

公式LINE（sunriseサーバー用）のメニューから開くページを、松浦様が「許可」した人だけ使えるようにする仕組みです。
管理画面で、誰が使っているか（使用中・最後に使った日時）を見て、「許可」「停止」を押せます。

**1. LINE Developers でログイン用の設定を作る（5分）**
1. https://developers.line.biz/console/ を開き、公式LINE（sunriseサーバー用）と同じ「プロバイダー」を選ぶ
2. 「新規チャネル作成」→「LINEログイン」→ アプリタイプは「ウェブアプリ」で作成。できたら「チャネルID」を控える
3. 「LIFF」タブ →「追加」：サイズ「Full」、エンドポイントURL `https://sunrise-kaitai.github.io/line/`、Scope は `openid` と `profile` にチェック → 作成。「LIFF ID」を控える
4. チャネルの状態を「開発中」から「公開済み」にする（開発中のままだと松浦様しか入れません）

**2. スプレッドシート「sunrise 見積書一覧」の Apps Script を新しくする（5分）**
1. 「拡張機能」→「Apps Script」を開き、中身を全部消して `ops/mitsumori-sheet.gs` の内容に置き換えて保存
2. 「プロジェクトの設定」→「スクリプト プロパティ」に2つ追加
   - `LOGIN_CHANNEL_ID`：1-2 で控えたチャネルID
   - `SECURE_KEY`：今のメニュー「見積書作成」のリンクの `#k=` より後ろの文字（会社情報を開く鍵）
3. 上の関数の選び欄で `setup` を選んで「実行」（許可の画面が出たら許可）
4. 「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「新バージョン」→「デプロイ」（URLは変わりません）

**3. Claude に「LIFF ID」を送る** → サイトに入れて公開します（ここで入口チェックが始まります）

**4. 松浦様が最初に管理画面を開く**
`https://liff.line.me/2012260278-4lkJYixg/kanri/` を松浦様のLINEで開く。最初に開いた人が管理者になります。
※ 必ず松浦様が一番に開いてください。

**5. 公式LINEのメニューのリンクを差し替える**
- 見積書作成 → `https://liff.line.me/2012260278-4lkJYixg/mitsumori/`
- スレッズ投稿 → `https://liff.line.me/<LIFF ID>/threads/`
社員の方がメニューを押すと「許可待ち」になるので、管理画面で「許可」を押してください。
